# Downstream evidence utility benchmark

This versioned offline benchmark derives a bounded, citation-valid evidence-review task from immutable F034/F035
observations. The protocol freezes the method on F025 before one F034 evaluation. It measures packet completeness,
coverage, trust, review-item effort and retrieval time-to-ready—not human comprehension or answer correctness.

See `specs/036-downstream-evidence-utility/contracts/downstream-utility-evidence.md` for the evidence contract.
