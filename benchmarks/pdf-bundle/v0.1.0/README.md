# F023 offline PDF readiness benchmark

This frozen benchmark answers one bounded question: can the exact reviewed Docling 2.114.0 five-file bundle be
transferred, independently verified and used by fresh socket-denied workers to convert the redistributable synthetic PDF
without any provider-cache authority?

It performs one excluded warm-up and three retained conversions. The result preserves per-run wall/CPU/RSS facts,
canonical-native identities, evidence/page/anchor counts, exact installation/package identities and a closed readiness
decision. The validator does not call the producer or Docling; it recomputes all identities, summaries, thresholds and
the Markdown projection from raw committed evidence.

`PDF_OFFLINE_READY` does not claim real-world PDF quality, OCR quality, semantic answer quality, general hardware
latency or legal certainty. Those questions belong to F024 and F025.
