# Provider-Neutral Retrieval Benchmark v0.1.0

This frozen F029 protocol compares the F027 lexical and F029 semantic profiles using the unchanged F025 questions,
support atoms, source fitness and redistributable F024 corpus. Both treatments receive the original direct question;
no operator keywords, translation dictionary or generated answer is used. F028 ingests CSV through the same product path
as every other supported format.

The binding run uses two fresh workspaces, the verified offline PDF bundle and the exact six-file multilingual E5 bundle.
Published observations contain evidence IDs, source keys, evaluation facts, timings and body-free provider metrics only.
They contain no document text, query text, vectors, local paths, host facts or raw failures.

Readiness requires complete citations and unsupported-question abstention, identical semantic projections, no regression
of overall full support, atom recall or source recall, plus non-regression and a strict improvement on each frozen German
question. A negative result remains a valid, publishable measurement.
