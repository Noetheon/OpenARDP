# F024 real-world corpus baseline

This frozen protocol measures exact offline structural parsing of the six-file `openardp-realworld/v0.1.0` corpus. Each
asset is parsed twice from a fresh provider boundary. Results retain source, recipe, native and ordered-block identities;
counts; anchor classes; retrieval/pointer checks; wall/CPU time; peak RSS; and stable outcomes. They retain no source,
native or extracted body.

`REALWORLD_BASELINE_READY` means only that this exact corpus passed the locked structural/offline/resource checks on the
declared environment. It does not establish answer correctness, retrieval relevance, ranking/citation quality, legal
certainty, publisher endorsement or performance over a broader document population. Those semantic claims remain F025.
