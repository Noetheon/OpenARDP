# Non-goals

**Status:** Active project policy adopted by Feature 005A.

OpenARDP must not:

1. implement its own PDF, DOCX or PPTX layout parser;
2. flatten DoclingDocument into a competing full document IR;
3. define a generic memory protocol for all agents;
4. execute instructions found in source documents;
5. require MCP for storage or core operation;
6. make embeddings mandatory;
7. equate cryptographic integrity with truth or trustworthiness;
8. promise exact cross-parser semantic equivalence;
9. claim standard status based on one implementation;
10. optimize only against a deliberately weak raw-reparse baseline;
11. register MIME types or file extensions before naming and adoption review;
12. include enterprise connectors in the trusted core before least-privilege validation.
