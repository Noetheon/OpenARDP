# OpenARDP multilingual E5 small bundle v1

This directory commits only the exact source lock, expected runtime manifest, model notice and MIT license. The six model
files remain outside Git and total 492,794,646 bytes.

Provisioning is an explicit connected operation. Runtime verification and inference are offline, reject ambient caches
and independently require this committed source lock. The profile is fixed to `intfloat/multilingual-e5-small` revision
`f470c6a1a906014160ece1968c484b275f0396de`, SafeTensors, 384 dimensions and 512 input tokens.
