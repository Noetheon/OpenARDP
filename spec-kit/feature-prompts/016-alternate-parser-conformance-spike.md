# Feature 016 — Alternate parser conformance spike

## Goal
Test whether the public evidence contracts are genuinely provider-neutral rather than Docling-shaped.

## Scope
Implement the smallest independent producer or consumer using a second parser or standalone validator in another language/process. Cover text plus at least one page/table anchor class. No production-quality feature breadth required.

## Decision
Report contract friction, Docling leakage and required changes. Breaking experimental changes are allowed with migration evidence. The feature may falsify provider neutrality and recommend narrowing the claim.
