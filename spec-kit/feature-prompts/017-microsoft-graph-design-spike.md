# Feature 017 — Microsoft Graph design spike

## Goal
Validate a mock-only least-privilege enterprise connector architecture.

## Scope
SharePoint/OneDrive identity, eTag/version/change-token mapping, permission snapshot references, deletion/tombstones, tenant boundaries, throttling/retry and change notification design. No credentials or production calls.

## Deliverables
Threat model, data-protection assessment, permission matrix, mocked adapter/contracts and explicit go/no-go criteria.
