# Feature 018 — Repository hygiene and maintainability

## Goal
Reduce accumulated maintenance risk after the completed roadmap without changing product behavior or public contracts.

## Scope
Repository-wide maintainability audit, behavior-preserving decomposition of the highest-risk orchestration hotspots,
regression guardrails, reliable focused/full validation commands, documentation synchronization and generated-file
hygiene. No schema, identity, storage-layout, application-version or release-decision change.

## Deliverables
Audited maintainability baseline, focused characterization tests, smaller orchestration units, deterministic regression
check, corrected validation guidance, synchronized project status and exact before/after evidence.
