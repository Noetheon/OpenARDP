# Feature 019 — CI cost and latency optimization

## Goal
Reduce GitHub-hosted runner cost and feedback latency without reducing final cross-platform test inventory, branch
coverage, supply-chain hardening or release-evidence quality.

## Scope
Deterministic changed-path classification, Draft-to-Ready execution, one Linux coverage/platform-independent gate,
complete no-coverage macOS/Windows final suites, bounded uv caching, separate release-boundary evidence workflow,
measured cost policy and solo-safe `main` protection. No product runtime, schema, identity, version or release-decision
change.

## Deliverables
Versioned CI policy, deterministic audit/classifier/estimator, two hardened workflows, dated cost evidence, tests,
operating guidance, remote three-platform evidence and protected-main verification.
