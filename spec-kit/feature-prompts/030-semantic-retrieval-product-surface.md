# Feature 030 — Semantic retrieval product surface

Expose the validated F029 hybrid multilingual retrieval profile as an explicit local product capability. Add bounded
CLI context compilation and optionally configured MCP compilation while retaining the exact F027 lexical profile as the
provider-free default. Semantic setup is authorized only by local process-start configuration, binds the exact verified
model bundle and source lock, and fails closed when unavailable or mismatched. Measure cold and warm execution, cache
reuse, peak worker memory and latency on the frozen redistributable corpus. Do not add answer generation, persistent
vectors, a vector database, cloud/network behavior or a new retrieval policy.

Complete the full Spec Kit lifecycle, tests, documentation, independent measurement validation, repository gates and a
single feature PR.
