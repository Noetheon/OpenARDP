# F025 contract surfaces

F025 adds benchmark contracts rather than a stable runtime API:

- `benchmarks/semantic-e2e/v0.1.0/questions.schema.json` closes the human-reviewed question/ground-truth set;
- `benchmarks/semantic-e2e/v0.1.0/questions.json` pins natural-language, answer-support and source-fitness inputs;
- `benchmarks/semantic-e2e/v0.1.0/protocol.json` freezes treatments, metrics, thresholds, resources and privacy; and
- the five-file result directory is independently regenerated by `scripts/validate_semantic_e2e_benchmark.py`.

The binding product surface remains the existing text/rich ingestion and `ContextCompilerService`. Operator keywords,
the exhaustive oracle and source-fitness rubric are benchmark apparatus, not new public OpenARDP APIs.
